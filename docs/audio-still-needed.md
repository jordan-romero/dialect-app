These sets are complete on S3 and were left unattached on purpose. Please don't
"fix" them without re-reading the doc first.

| Set     | Exercise                         | Why not                                                                          |
| ------- | -------------------------------- | -------------------------------------------------------------------------------- |
| `8A.*`  | Transcription Matching (quiz 22) | Instruction never mentions audio, and hearing "singing" answers Q8 outright      |

and attaching it would quietly make the exercise easier than it should be.
